# Preflight

This folder holds the final checks for the exact command or script about to be
presented to a person. Start with [terminal preflight](terminal.md).

Use established [system facts](../systems/README.md), [shell constraints](../shells/README.md)
and [user conventions](../user/README.md). Resolve unknowns with
[probes](../probes/README.md); exercise disposable [fixtures](../fixtures/README.md)
through [tests](../tests/README.md). Preflight checks the intended target, source
and destination state, mutation boundary and verifiable postcondition. It does
not replace executed tests or turn a checklist into evidence of live success.
See [local agent rules](AGENTS.md).
