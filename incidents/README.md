# Command-preparation incidents

Record cases where a human-facing command escaped preparation with a bad
assumption.

Each incident should capture:

- what was served;
- what assumption was wrong;
- what direct evidence was already available or should have been requested;
- what fixture/probe/test would have caught it;
- the durable rule or regression work that follows.

The point is not a diary of typos. Keep failures that improve the preparation
process.
