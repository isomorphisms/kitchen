# Agent instructions: incidents

Inherit the [root instructions](../AGENTS.md) and all intervening directory rules.

Follow the [README](README.md). Preserve the original request, faulty output,
user correction or observed error, source/date and evidence level when available.
Distinguish actual observations, user reports, assistant claims and hypotheses.
Do not invent a transcript, consequence or root cause.

Use public-safe summaries and synthetic regression inputs, not private mail or
credentials. Link each incident to a known-bad case, an independently justified
expected result and a correct counterpart when implemented. An issue or written
test plan is not a completed regression. Preserve historical context when
linking a repair instead of erasing the failure record.
