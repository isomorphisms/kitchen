# Agent instructions: user

Inherit the [root instructions](../AGENTS.md) and all intervening directory rules.

Preserve the user's explicit preferences and corrections, with context or
provenance where available. Keep them distinct from observations of a
particular machine. A preferred path is not an existing directory, and an
available default is not permission to ignore a preference.

Start with the [index](README.md). Before offering commands, check both the
applicable conventions here and the selected [system](../systems/README.md).
Do not silently replace readable spellings or the observed filesystem layout
with generic Unix habits. Store only task-relevant, public-safe preference
summaries; do not copy private conversations into this repository.
