# User conventions

This folder holds desired conventions, not claims about current machine state.

- [Filesystem preferences](filesystem.md): preferred layout and path discipline.
- [Shell style](shell-style.md): readable naming and command-presentation choices.

Read these alongside the selected [system profile](../systems/README.md) and
[shell constraints](../shells/README.md). A preference for ~/opt/bin does not
establish its existence on a particular host. Preserve explicit corrections
rather than making the user repeat them. See [local agent rules](AGENTS.md).
