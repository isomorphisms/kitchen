# Sources and ownership

This folder records where Kitchen's facts and guardrails come from so agents
can verify, refresh and reconcile them instead of treating copies as timeless.

- [Cat Food](catfood.md): provenance for device and observed environment facts.
- [AICI](aici.md): provenance for reusable acceptance and evidence rules.

Kitchen owns preparation and its local fixtures, not a replacement device
inventory or a competing acceptance policy. Cockswain supervises follow-up;
its planned Kitchen watcher is tracked in
[Cockswain #34](https://github.com/isomorphisms/cockswain/issues/34), paired with
[AICI #187](https://github.com/isomorphisms/ai-ci/issues/187).

Keep source scope, dates and revisions where available. Mark unverified or
stale claims instead of filling gaps with generic assumptions. Read the
[local agent rules](AGENTS.md) when mirroring or updating facts.
