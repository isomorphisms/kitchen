# Agent instructions: sources

Inherit the [root instructions](../AGENTS.md) and all intervening directory rules.

Use the [index](README.md) to preserve ownership and provenance. For mirrored
facts retain the source repository/path, revision or dated evidence where
available, target scope and relevant limitations. Mutable branch links are
starting points, not proof that an earlier observation remains current.

Cat Food owns device/host facts; AICI owns shared evidence guardrails; Kitchen
applies them during preparation; Cockswain supervises follow-up. Do not copy
large source trees or silently replace upstream ownership. Record discrepancies
and the evidence resolving them. Never publish private source records,
credentials or unrelated personal details to strengthen a citation.
