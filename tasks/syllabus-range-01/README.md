# Exact-source ICU syllabus range candidate

Build/install the published candidate Idriç/ICU/AICI source revisions using the actual pinned Idriç compiler and ICK. The recipe refuses dirty tracked ICU/Idric-Net sources. This is a candidate host acquisition qualification, not a public-client release or physical-device acceptance. `protocol-version-probe` is an explicit candidate interface; `icu get-range` is not claimed.

Compared with the retained `icu-finish` recipe, this numbered recipe binds the finite HTTP version API, bounded chunk decoder, Content-Range capture and source probe, then installs that probe with the same native provider. Independent capture, proxy and range acceptance remain separate executable stages in Flexible Pipes. Real source response semantics remain separate from transport exit status.
