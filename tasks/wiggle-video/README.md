## Data contract, wiggle-v1

Files are UTF-8 TSV, no header except the generated timeline. Times and numeric
values are exact decimal or rational text. Time zero is the first frame onset;
frame i has time i ÷ fps. Frame count includes start/end holds. A slow renderer
never changes that clock. Events after the final frame onset are rejected.

| File | Rows |
| --- | --- |
| run.tsv | Unique key/value pairs: schema=wiggle-v1, evidence=offline-computed, origin=scripted/recorded-gesture/audio-driven, fps, frames, width, height; backend and optional audio retained verbatim |
| controls.tsv | name, kind, interpolation, units/coordinates, minimum, maximum |
| events.tsv | rational time, globally increasing sequence number, control name, value |
| inputs.tsv | relative asset path, SHA-256; all audio must be listed |
| tools.tsv | adapter/build.sh/1.sh, SHA-256 of the executable and canonical builder files |
| sources.tsv | absolute repository root, exact origin URL, full commit |

`scalar` and `coordinates` (two coordinates separated by comma) support linear
or hold. `gesture` and `discrete` are event-only, with app-owned payloads.
`sample_index` is an integer held between explicit source-sampled events.
Every non-event control needs a value at time zero. Duplicate control timestamps
are forbidden; same-time distinct events retain their global order. Initial
states, pauses, resume, camera and domain operations belong to the adapter.
Recorded gestures must retain their actual times and coordinate convention;
this planner must not relabel a scripted trace as a human recording.

The adapter executable receives TRACE TIMELINE OUTPUT. TRACE is a snapshot,
TIMELINE is the evaluated TSV with frame/time/role/control/value/source_time/order,
and OUTPUT contains the empty frames directory. The adapter must call the real
engine, write `frame-000000.ppm` onward, and retain exact app checkpoints in
`states.tsv`. The common layer does not draw, interpolate images or interpret
group elements. Geometry/colors stay with the producer. The initial boundary
accepts canonical binary P6 PPM with even dimensions; PNG support is pending.

Candidate 2 snapshots assets, checks declared tracked source identities and
hashes, retains failed attempts, refuses existing output and invokes the exact
existing `movie-from-stills/build.sh` through its declared POSIX interpreter.
This is the existing encoder interface, not a new authored shell procedure.
Production ends at PRODUCED_NOT_ACCEPTED. AI-CI checks retained frame bytes and
decoded MP4 pixels independently; domain oracles and source-to-executable build
receipts are additional requirements, not inferred from pixel agreement.

## Remaining qualification

This is an implemented, tested **bounded candidate**, not completed WIGGLE-VIDEO-01.
Application movies, synchronized audio oracle, compiler/backend source closure,
continuous persistent adapters, interruption/out-of-space/encoder-failure
coverage and large-stream operation remain open. The planner currently retains
the complete evaluated plan and scans the event list; it is not a constant-space
stream processor. AI-CI's first pixel gate restarts decoding per frame and is
for small fixtures, not long captures. Do not promote its tests into full
application mathematical or physical-device acceptance.
