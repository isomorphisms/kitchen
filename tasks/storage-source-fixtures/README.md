# Retained-source host procedure

`1.grease` is a tested host qualification procedure, using explicit absolute
`GREASE`, `STORAGE_IB_ROOT`, `STORAGE_IB_REVISION` and an unused
`STORAGE_RECEIPT_DIR`. It checks canonical repository identity and the committed
implementation/test bytes before executing IB's real fixture suite. Streams
are private; the receipt records their hashes and exact source/runtime inputs.

This is seeded for Flexible Pipes execution and AICI fixture receipt validation.
It is not a mobile install procedure or an authorized private-source transfer.
Live Drive acquisition and SDF archival retain their separate credentials and
private resumable receipts. Cat Food issue 117 must first deliver qualified
commands/helpers and the approved APK signer for a concrete C67 procedure.

`test.grease` clones the supplied committed IB source into temporary state,
runs twice from `/`, checks deterministic semantic output, and refuses both
receipt reuse and modified implementation bytes before execution. No mailbox,
browser database or personal export is read.
