# RHS hosted acceptance requirements

Target: GitHub-hosted Ubuntu x86_64. Cat Food owns acquisition; this task runs only already-acquired executables. Flexible Pipes owns admission, stage sequencing and stream receipts. AI-CI owns independent acceptance.

The glyph command takes absolute RHS root, fresh evidence destination, checked Ithon entrypoint and AI-CI verifier. Reject missing executables, relative paths, wrong source/fixture/compiler pins, unrelated source mutations and differing observed output. Never infer physical keyboard acceptance. The checker compiles the original and migrated fixtures at O0/O2 and retains their raw output and hashes.

Tests precede consumer acceptance: AI-CI source controls include a valid seven-quotient migration, comment/string mutations, a changed divisor, a missing substitution and extra unrelated bytes. A missing input or failed command must retain a nonzero stage exit.
