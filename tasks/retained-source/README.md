# Retain an already selected bounded source

`1.grease` runs the existing IB public intake with explicit runtime, checkout,
source bytes and provenance paths. It has no dependency installation, compiler,
Drive download, private discovery or upload hidden inside it. Source/manifest
paths may be selected by the caller; the working directory is arbitrary.
Preparation must first resolve the exact target's Cat Food delivery and source
revision. The current C67 bundle is still blocked under Cat Food #117; do not
serve a phone procedure that substitutes a source build for that package.

The manifest/decoder contract lives in IB's `docs/retained-source-intake.md`.
Per-source privacy/exposure is an explicit input. Do not turn mail's policy into
a universal requirement for ordinary browser/history material. The command's
source ID is a machine output; colored preparation diagnostics go to stderr.
This procedure is repository-tested on disposable Linux data only, not a C67
installation or source intake receipt. Flexible Pipes owns repeatable contract
execution; AICI owns its evidence boundary.
