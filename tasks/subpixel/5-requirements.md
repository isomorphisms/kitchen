Version 4 qualifies only the historical local-patch producer and rational
oracle. Version 5 must execute the accepted whole-path/font producer at
0a09edede932ba80feb7f35addede3eb17baf6f3 and independent ai-ci acceptance at
5f6abcc9185dc960d445e7a567b5441f23973a15. This is a new attempt; version 4
and its receipts remain historical evidence.

Target: disposable x86_64 Linux / GitHub-hosted Ubuntu. Use the verified Grease
launcher, source-pinned ICK and ICK-built Ike. Keep the existing ICK bootstrap
and producer/oracle POSIX interfaces explicit. No consumer C reaches the host
compiler; the host driver links ICK objects only.

Before execution, require clean exact source inputs, authenticated runtime and
recipe material, canonical absolute workspace, and fresh output directories.
The producer preview must run the native tests and emit all four path modes,
32 font panels, font metrics and actual individual sample masks. Retain those
bytes, native binaries and their hashes, rather than only the old showcase.

Require both independent PASS markers: original rational/alpha checks and
408 path + 463 glyph assertions with four path source mutants, two bad glyph
topologies and four original compiled mutants. Retain every rejection log.
Require the unchanged exact receipt checker and its wrong-target/final-result
negative controls. A missing path/font marker must fail even if the original
rational marker appears. Seal result.tsv itself as well as all retained files.

Tests before an expensive build: absent workspace, corrupt runtime, wrong
producer revision and a legacy-only oracle log must fail for the intended
reason, before later stages or evidence sealing. A positive log with both
markers must pass. The actual registered workflow supplies the full positive
compiler/producer/oracle execution; parsing alone is not qualification.

This host result does not qualify Conway's bridge, production admission, model
dispatch, APK publication or physical A1/C67 behavior. Those obligations retain
their separate evidence. No merge authority is granted.
