# Amazon.jobs Idriç CLI — Kitchen acceptance

The human-authorized Amazon.org research enters Flexible Pipes first.
`tasks/amazon-jobs-cli/1.grease` provides *separate* `preflight`,
`build`, and `test` operations. No compiler, network library,
Python client, provider token or JSON fixture is provisioned inside it.

On the pinned Linux x86_64 host, the task checks the exact git head of
`dilapidated-shed/idric-cli`, requires the maintained Idriç executable,
compiles `checkpoints/amazon-jobs/AmazonJobs.idric` with the contributed
JSON package, runs the compiled fixture test, then tests the **stable Cat Food
installed command** outside the checkout. `test` refuses a command whose
resolved path is not the exact executable it built. Cat Food must first link
the executable as `$CATFOOD_ROOT/bin/amazon-jobs`.

AICI additionally verifies its independently authored structural contract
with five deliberately broken fixtures. The separate live-provider stage
takes the installed command's real output and exit status; a transport
failure is not a successful zero-job census. Neither a source-only
contract nor synthetic fixture establishes the current Amazon organization.

A1 ARM32 and C67 ARM64 compilation/execution are NOT_RUN.
