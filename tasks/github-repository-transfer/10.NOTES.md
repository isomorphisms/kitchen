# Candidate 10: compact handoff without removing transfer checks

October 8, 2026. Candidate 9's standalone artifact was useful and passed its
Linux API fixtures, but its entire five-kilobyte body was cumbersome as a routine
terminal handoff. Its imperative checks remain necessary.

Candidate 10 adds a descriptive, explicitly named argument interface to those
same checks. `transfer-github-repository.grease` is the maintained public source;
`10.grease` preserves the exact versioned candidate bytes. A generator can embed
the complete program and bind its arguments, or acquire this exact immutable
program with a checked SHA-256 before invoking the visibly named operation.
Acquisition is not itself qualification or live-transfer authorization.

Requirements are recorded in `compact-handoff-requirements.md`. The qualification
must execute exact rendered bytes, exercise failed/partial/changed acquisition,
and keep independent API observations and positive twins. No Android claim is
made from Linux fixtures. The complete artifact remains available without
requiring acquisition at execution time.
