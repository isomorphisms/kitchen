# Mostow mechanical encounter preparation

Invoke `2.grease TASK_DIRECTORY APPLICATION_DIRECTORY TARGET` with explicit
`MOSTOW_HOST_COMPILER`, `MOSTOW_GREASE`, `MOSTOW_IKE`, and for rendering
`MOSTOW_GL_ROOT`. `accepted-host` additionally requires `MOSTOW_AI_CI`.
The caller supplies `IKE_RECEIPT`; the adapter binds the Ikefile digest and
uses Grease's actual source-file recipe protocol. All paths are absolute.

`kernel.grease TASK_DIRECTORY APPLICATION_DIRECTORY KERNEL` selects one of
Mostow's explicit mathematical kernel tests. The application owns model,
fixtures, negative controls and renderer. Independent verifier source belongs
to AI-CI. Kitchen sequences these existing responsibilities without owning
another mathematical implementation or a device registry.

The Mostow `tools/run-fp-host.grease` caller pins this source, compiles pinned
Ike with the declared ICK compiler and executes the stage through FP. The
complete host assertion set runs for `accepted-host`; no package or phone
acceptance is inferred. `host-render` also regenerates the unchanged original
sheet fixture; do that when generator inputs changed, not on every rerun.

Two initial rejected attempts are retained with their exact error causes.
The corrected adapter executed from a different working directory through
FP. An explicit nonexistent compiler was rejected before any recipe. Actual
mutant failures propagated from the mathematical fixtures through Grease,
Ike and FP; a successful compiler invocation alone is never the result.
