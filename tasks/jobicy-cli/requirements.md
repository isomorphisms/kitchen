# Jobicy build and installed-command acceptance

Target: observed Ubuntu 24.04 x86-64 disposable execution host, hostname
f6b275f50fa0. This task does not qualify a phone or tablet.

The implementation must compile with the maintained Idriç Chez backend;
ICU/Idric-Net owns HTTP, and pinned ICK compiles the native ICU library.
Preflight must reject wrong source revisions, absent dependencies, invalid
absolute roots and undeclared substitute compilers. Provisioning is a distinct
operation; product build and test must acquire nothing.

Install to an explicit absolute prefix, check the source digest inside the
application directory, invoke the installed program outside its checkout, and
exercise deterministic fixtures and actual loopback HTTP through ICU.
Positive and negative cases cover exact IDs, description bytes, pagination,
status, errors, Unicode, options and the bounded hourly synchronization guard.

The ai-ci oracle must independently compare selected semantic output to its
expected TSV, and reject a mutant equating unknown with closed. Live provider
execution has its own recorded exit and raw public response; a transport failure
must remain BLOCKED and cannot invalidate or inflate separately executed local
checks. Neither local tests nor compilation establishes physical acceptance.

An existing output prefix may be updated with the same explicit source. Test
captures use a new temporary directory; failures retain evidence. No user source
or existing unrelated program is removed. Scripts resolve all paths explicitly
and may be launched from an arbitrary directory.
