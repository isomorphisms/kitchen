# Dirichlet source and coefficient execution

These numbered Grease candidates run through the maintained Flexible Pipes command controller and real Ike. They perform no downloads, toolchain bootstrap, phone actions, service activation or publishing.

- `1.grease`: exact original signed `GeometricFinite.idric` attempt.
- `2.grease`: one separately content-pinned Idriç module, with fresh source/TTC paths and explicit base-commit versus dirty-file identity.
- `3.grease`: the exact JS coefficient module and its own tests in an isolated snapshot.
- `4.grease`: a separate AI-CI checker over frozen module bytes, with independent checker identity and expected module digest.

Every task requires absolute resolved runtime paths, an exact source base HEAD, content digests and a new output directory. The outer invocation creates a literal Ikefile, binds its digest and executes it with the declared Grease source-file runner. The child records source/runtime identities and raw compiler/test streams. Reusing a completed output directory fails. The caller must read the actual FP and Ike results, not infer acceptance from an existing output file.

The initial signed Idriç source failed because compiler `94dfd99bd3e376507fedc8611053b7173b2519f0` did not resolve `±Number` or `−`. This failure remains separate from the successful natural-number proof. A deliberately false equality is retained as an expected checker rejection; it remains a failed compiler execution rather than being rewritten as a positive compiler pass. Fresh TTC output is required because a historical compiler can print errors while returning zero.

The JS path computes finite coefficients with BigInt; it does not prove an infinite modular-form theorem or substitute for native proof acceptance. The independent checker path records its own mathematical result while keeping AI-CI promotion, registered-service leases, platform delivery and physical devices separate.

Current host qualification uses an existing native Grease artifact with `ASAN_OPTIONS=detect_leaks=0` in the restricted container. This is a diagnostic runtime limitation, not complete Grease producer/release acceptance. The actual task bytes, source snapshots and run receipts are preserved in the companion Flexible Pipes Dirichlet campaign evidence.
