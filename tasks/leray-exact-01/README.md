# Exact periodic Beltrami host qualification

Requirements precede this candidate: source artifact and acceptance are specified
by SUN LERAY-EXACT-01. Target is an Ubuntu 24.04 Linux x86_64 build host.
Arguments name the producer, independent AI-CI source, pinned Ike source,
qualified ICK compiler, compiled Grease, and a fresh evidence directory.

Version 2 runs a C11 build through Ike with a digest-bound Ikefile. It compares
two executable builds and two runtime outputs, then runs the independent AI-CI
oracle. It observes 14 invalid-parameter process exits and corrupts each of the
13 numeric diagnostic columns, including all continuous/semidiscrete reference
columns. Every corrupt output and truncated suite must be rejected.

The output records host/runtime, compiler, source and binary identities, build
receipt, producer tables, independent acceptance, and rejection evidence.
Divergence is scoped to the z-only ansatz. No general 3-D solver, device result,
production admission, or merge is claimed.

The existing ai-ci/ick-host action owns compiler/bootstrap/runtime acquisition.
It is a prerequisite, not a replacement numerical result. A missing compiler
blocks this recipe; no stock consumer compiler fallback is provided.
