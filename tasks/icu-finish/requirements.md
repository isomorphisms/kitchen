# ICU host build and installation

The explicit ICU finish envelope owns this operation. Target: observed Linux
x86-64 host; source pins, compiler prefix and runtime are supplied explicitly.
Build with the verified Idriç Chez backend and pinned ICK, using installed
Idric-Net. Install ICU and its response probe with their native transport beside
each Chez application; execute them from outside the checkout.
No dependency acquisition, source substitution, refC, curl implementation,
mobile compilation or physical-device claim occurs here.

AICI owns disposable transport fixtures, exact expected behavior and rejecting
mutants. The receipt must preserve failed executions and exact source hashes.
