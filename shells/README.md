# Shell languages and runtimes

This folder records interpreter semantics and implementation constraints,
separately from host facts and personal preferences.

The current language note is [Grease/YSH](grease-ysh.md). Add Bash, POSIX sh or
other notes when needed and supported by evidence; their mention here does not
claim an existing profile, installed interpreter or completed compatibility test.

Select both a [system/execution context](../systems/README.md) and a shell.
Read [user spellings and conventions](../user/README.md) separately: an alias or
preferred spelling is not automatically a language feature. See the
[local agent rules](AGENTS.md) before adding or applying a shell note.
