# Agent instructions: shells

Inherit the [root instructions](../AGENTS.md) and all intervening directory rules.

Identify the actual interpreter, relevant version and supported features.
Read the applicable note from the [index](README.md); do not equate an OS name,
login-shell setting or preferred spelling with the executing interpreter.

Test syntax and behavior in that interpreter or label the gap. Distinguish
Bash, POSIX sh and Grease/YSH; a shell-looking command is not proof of compatible
quoting, expansion or control flow. Separate user aliases from verified language
features. Keep machine paths in [systems/](../systems/README.md) and spelling
preferences in [user/](../user/README.md). Do not claim an undocumented shell
profile or unexecuted target test exists.
