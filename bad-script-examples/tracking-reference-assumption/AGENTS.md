# Fetched objects versus refs

Inherit the [root instructions](../../AGENTS.md) and
[specimen-preservation rules](../AGENTS.md). Read the
[case account](README.md); keep bad evidence unchanged.

Test retrieval that supplies the object but not the tracking ref expected by
the next command. Verify that exact ref separately, and include a correctly
established counterpart. Use disposable repositories; do not alter the user's
tracking refs merely to reproduce the historical failure.
