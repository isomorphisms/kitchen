# Container layout

Inherit the [root instructions](../../AGENTS.md) and
[specimen-preservation rules](../AGENTS.md). Read the
[case account](README.md); keep bad evidence unchanged.

Reproduce the particular image's required absolute paths, not a guessed
container home. Test the wrong layout and the required layout independently.
Historical paths in the specimen describe that failure, not every container;
do not change a real image or host layout just to make the test pass.
