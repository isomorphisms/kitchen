# Mailbox preservation

Inherit the [root instructions](../../AGENTS.md) and
[specimen-preservation rules](../AGENTS.md). Read the
[case account](README.md); keep bad evidence unchanged.

Use synthetic mail only. Keep selection correctness, archive durability and
source preservation separate; include interrupted and repeated attempts.
Assert message bytes and resulting contents, not just exit status. Link shared
mailbox behavior fixtures to the mbox repository rather than creating a second
authoritative mail corpus here. Never open the live spool for this test.
