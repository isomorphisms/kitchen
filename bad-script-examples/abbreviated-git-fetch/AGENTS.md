# Git fetch inputs

Inherit the [root instructions](../../AGENTS.md) and
[specimen-preservation rules](../AGENTS.md). Read the
[case account](README.md); keep bad evidence unchanged.

Separate a human shorthand from a fetchable remote ref or an object the remote
actually permits requesting. Test absent or unresolvable inputs as well as a
verified fetchable counterpart; spelling out a hash alone is not proof it can
be fetched. Use disposable local repositories, not the user's working clones.
