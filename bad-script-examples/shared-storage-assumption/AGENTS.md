# Storage availability

Inherit the [root instructions](../../AGENTS.md) and
[specimen-preservation rules](../AGENTS.md). Read the
[case account](README.md); keep bad evidence unchanged.

Distinguish configured storage, currently mounted storage and permission to
access it in the selected execution context. Test missing, inaccessible and
changed storage as well as an observed accessible counterpart. A saved mount
path or successful check from another context is not present access evidence.
