# Source versus terminal paste

Inherit the [root instructions](../../AGENTS.md) and
[specimen-preservation rules](../AGENTS.md). Read the
[case account](README.md); keep bad evidence unchanged.

Treat the specimen as inert text. Test the instructions' delivery boundary:
which text creates a source file, which invokes its interpreter and which is
shell input. Use a disposable fixture for an intentionally wrong-context test;
never paste the specimen into the user's terminal to demonstrate the mistake.
