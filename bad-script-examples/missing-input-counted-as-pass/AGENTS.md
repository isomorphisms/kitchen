# Unavailable evidence

Inherit the [root instructions](../../AGENTS.md) and
[specimen-preservation rules](../AGENTS.md). Read the
[case account](README.md); keep bad evidence unchanged.

Keep missing input, permission failure, malformed input, zero executed cases
and partial enumeration distinct from successful required coverage. Supply a
complete independently expected counterpart. Neither a count of zero failures
nor a skipped required check may be converted into a passing acceptance result.
