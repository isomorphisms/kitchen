# Evidence levels

Inherit the [root instructions](../../AGENTS.md) and
[specimen-preservation rules](../AGENTS.md). Read the
[case account](README.md); keep bad evidence unchanged.

Keep parse, signature and build checks separate from installation, launch and
behavior on the named device. Tests of report classification should reject a
device-acceptance claim supported only by static checks. A classification test
is itself not a device test; leave unavailable target evidence explicit.
