# Agent instructions: assumptions

Inherit the [root instructions](../AGENTS.md) and all intervening directory rules.

Classify knowledge using this folder's [README](README.md): observed,
preference, constraint, derived, unknown or deferred. Keep source, date and
scope where relevant. Do not relabel an inference as an observation or a user
preference as proof of filesystem state.

Resolve factual disagreements using evidence from the exact target; a new
observation does not itself cancel the user's preference or authorize a setup
change. Keep unresolved and deferred work explicit. Link to the relevant
[system](../systems/README.md), [user](../user/README.md) or
[shell](../shells/README.md) note instead of inventing a second profile.
